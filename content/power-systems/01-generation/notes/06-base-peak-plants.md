## Splitting the load curve

Look at a daily load curve. Some part of the load is present **all 24 hours**; above it, some load comes only for a few hours.

![The load curve split by a horizontal line: below it is base load, above it is peak load](fig:c-ps1-base-peak)

- **Base load:** the part below the line, present round the clock, almost constant.
- **Peak load:** the part above the line, present only during some hours (morning and evening peaks).

Different kinds of plants are used for the two parts. The choice depends on **cost** and **how quickly a plant can start and change its output**.

## What a base load plant needs

A base load plant runs **all the time, at nearly full load**. So:

- its **running (fuel) cost must be low**, because it produces a huge number of units;
- a **high capital cost is acceptable**, because it is spread over many units (high load factor);
- it need **not** start quickly or follow load changes.

**Base load plants:** **nuclear**, large **coal (steam)** plants, **run-of-river hydro** (no storage, so the water must be used as it comes), combined-cycle gas plants.

## What a peak load plant needs

A peak load plant runs only a few hours a day. So:

- it must **start quickly** and **change its output fast**;
- its **capital cost must be low**, because it produces few units (low load factor);
- a high running cost is acceptable, because it runs only a few hours.

**Peak load plants:** **gas turbine**, **diesel**, **pumped storage**, **storage (reservoir) hydro**, run-of-river hydro **with pondage** (for part of the peak).

> **Remember:** base load → low running cost, high capital cost OK, slow start OK. Peak load → quick start, low capital cost, high running cost OK.

## Plants that do not fit neatly

- **Wind farms and solar plants** run whenever the wind blows or the sun shines; nobody can schedule them. They are **neither base load nor peak load** plants by choice; they are **variable (intermittent)** sources. A list of "base load plants" never includes wind farms.
- **Storage hydro** can do both: in the rainy season (plenty of water) it may run as base load; in the dry season it saves water for the peaks.
- **Diesel** plants are base load only in a small isolated system with nothing else.

## Worked examples

**Example 1.** Which of these are base load plants: (i) nuclear, (ii) run-of-river, (iii) pumped storage, (iv) diesel?
Nuclear and run-of-river are base load. Pumped storage and diesel are peak load. Answer: (i) and (ii).

**Example 2.** Which plant is most suitable for supplying peak loads: nuclear, steam, hydro, gas turbine?
All four can follow load in some way, but the classic peak plant is the **gas turbine**: lowest capital cost and starts in minutes. (Storage hydro is also good, but among the plants in such a list, gas turbine is the textbook answer.)

## Reserves

To keep the supply going if a unit trips, extra capacity is kept ready:

- **Spinning reserve:** generators already running and synchronised but not fully loaded; they can take extra load at once.
- **Hot reserve:** units kept hot (boilers warm) but not running; they can be started fairly quickly.
- **Cold reserve:** units available but shut down; they need hours to start.

## Summary of this topic

| | Base load plant | Peak load plant |
|---|---|---|
| Runs | 24 h, near full load | few hours |
| Running cost | must be low | can be high |
| Capital cost | can be high | must be low |
| Starting | slow is OK | must be quick |
| Examples | nuclear, coal, run-of-river, combined cycle | gas turbine, diesel, pumped storage, storage hydro |
